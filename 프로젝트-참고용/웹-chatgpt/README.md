# ChatGPT 분석 — IA · User Flow · Wireframe

> **분석 대상**: ChatGPT (OpenAI) — 데스크톱(chatgpt.com) · 모바일 · 2026년 8월 기준
> 화면을 만들기 전에 정하는 세 가지를, 순서대로 ChatGPT에 적용해 분석했습니다.

| 순서 | 이름 | 우리말 | 답하는 질문 |
|---|---|---|---|
| 1 | IA (Information Architecture) | 화면·메뉴 구조 | 화면이 몇 개이고 무엇이 어디에 있는가 |
| 2 | User Flow | 사용자 흐름 | 사용자가 어떤 순서로 움직이는가 |
| 3 | Wireframe | 화면 뼈대 | 각 화면에 무엇이 어디에 놓이는가 |

---

## 1. IA — 화면과 메뉴 구조

### 데스크톱 — 컴퓨터로 볼 때

데스크톱은 화면을 늘리는 대신 **한 화면을 영역으로 나눕니다.** 화면 하나에 영역이 셋입니다.

```
ChatGPT (chatgpt.com) — 화면 하나, 영역 셋
├── 왼쪽 (사이드바 — 항상 보임)
│   ├── 새 채팅 · 채팅 검색
│   ├── 라이브러리 · GPTs · 프로젝트
│   ├── 대화 기록 (오늘 / 어제 / 지난 7일)
│   └── 프로필 → 설정
├── 가운데 (대화 본문)
│   ├── 모델 선택 (본문 왼쪽 위 드롭다운)
│   ├── 주고받은 내용 (내 질문 오른쪽 · 답변 왼쪽)
│   └── 입력창 (+ 첨부 · 받아쓰기 · 음성 모드)
└── 오른쪽 (캔버스 — 필요할 때만 열림)
    ├── 문서 · 코드를 나란히 놓고 작업
    └── 직접 타이핑 수정 · 버전 이동 · 복사
```

### 모바일 — 폰으로 볼 때

모바일은 화면이 사실상 5개뿐이고, 중심은 **채팅 화면(S1) 하나**입니다.

```
ChatGPT 앱
├── S0. 온보딩·로그인 (첫 실행에만 잠깐)
├── S1. 채팅 화면 ★ 기본 화면 — 앱의 중심
│   ├── 상단 바 (≡ 사이드바 · 모델 선택 ▾ · ✎ 새 채팅)
│   ├── 대화 영역 (제안 프롬프트 → 내 질문 오른쪽 · 답변 왼쪽 전체 폭)
│   └── 입력바 (+ 첨부 · 입력창 · 받아쓰기 · 음성 모드)
├── S2. 사이드바 — 서랍 (S1에서 ≡ 또는 스와이프)
│   ├── 검색
│   ├── 새 채팅
│   ├── 라이브러리 · GPTs · 프로젝트
│   ├── 대화 기록 (오늘 / 어제 / 지난 7일)
│   └── 프로필 → S4. 설정 입구
├── S3. 음성 모드 (S1 입력바 오른쪽 버튼)
└── S4. 설정 (S2 프로필에서 진입)
    ├── 계정 · 구독 (Free / Plus / Pro)
    ├── 개인 맞춤 (맞춤형 지침 · 메모리)
    └── 앱 환경 · 데이터 제어
```

뼈대는 둘이 같습니다. 한 가지 눈에 띄는 점 — **모델 선택이 위쪽에 있습니다**(모바일은 상단 바, 데스크톱은 본문 왼쪽 위). 입력바 안에 두는 Claude와 갈리는 지점입니다.

## 2. User Flow — 사용자 흐름

### 데스크톱 — 컴퓨터로 볼 때

**Flow A. 처음 쓰는 사람 — 접속부터 첫 답변까지**

```mermaid
flowchart TD
    GA1(["브라우저에서 chatgpt.com 접속"]) --> GA2["로그인<br/>Apple / Google / 이메일"]
    GA2 --> GA3["시작 화면<br/>입력창이 화면 한가운데 · 제안 칩"]
    GA3 --> GA4["제안 칩을 누르거나 직접 입력<br/>Enter로 전송"]
    GA4 --> GA5["첫 답변 받음<br/>입력창은 하단으로 내려감"]
    GA5 --> GA6{"이어서 물어볼까?"}
    GA6 -->|"예"| GA4
    GA6 -->|"아니요"| GA7(["탭 닫기 — 다음에 다시"])
```

**Flow B. 매일의 핵심 루프 — 질문 ↔ 답변**

```mermaid
flowchart TD
    GB1(["chatgpt.com 접속"]) --> GB2["시작 화면<br/>로그인 유지 — 바로 도착"]
    GB2 --> GB3["질문 입력 · Enter"]
    GB3 --> GB4["답변이 실시간으로 출력됨<br/>— 스트리밍"]
    GB4 --> GB5{"다음 행동은?"}
    GB5 -->|"꼬리 질문"| GB3
    GB5 -->|"새 주제"| GB6["사이드바에서 새 채팅"]
    GB6 --> GB3
    GB5 -->|"용무 끝"| GB7(["탭 닫기"])

    classDef hot fill:#dbeafe,stroke:#2563eb,color:#1e3a8a;
    class GB3,GB4 hot;
```

**Flow C. 지난 대화 이어가기 — 클릭 한 번**

```mermaid
flowchart LR
    GC1["사이드바가 항상 보임<br/>서랍 여는 단계가 없음"] --> GC2{"찾는 방법"}
    GC2 -->|"검색"| GC3["채팅 검색"]
    GC2 -->|"스크롤"| GC4["날짜 그룹 목록"]
    GC3 --> GC5["클릭 — 대화가 가운데 열림"]
    GC4 --> GC5
    GC5 --> GC6["이어서 질문"]
```

**Flow D. 캔버스로 문서·코드 다듬기 — 데스크톱만의 흐름**

```mermaid
flowchart TD
    GD1["대화에서 문서·코드 요청<br/>'면접 답변을 문서로 다듬어 줘'"] --> GD2["오른쪽에 캔버스 열림"]
    GD2 --> GD3{"고치는 방법"}
    GD3 -->|"대화로 지시"| GD4["ChatGPT가 고쳐 줌"]
    GD3 -->|"캔버스에서 직접 타이핑"| GD5["내가 바로 편집"]
    GD4 --> GD6{"마음에 드나?"}
    GD5 --> GD6
    GD6 -->|"아직"| GD3
    GD6 -->|"예"| GD7(["복사해서 사용"])

    classDef panel fill:#dbeafe,stroke:#2563eb,color:#1e3a8a;
    class GD2,GD5 panel;
```

### 모바일 — 폰으로 볼 때

**Flow A. 처음 쓰는 사람 — 설치부터 첫 답변까지**

```mermaid
flowchart TD
    MA1(["앱 첫 실행"]) --> MA2["S0. 온보딩·로그인<br/>Apple / Google / 이메일"]
    MA2 --> MA3["S1. 빈 채팅 화면<br/>'무엇을 도와드릴까요?'"]
    MA3 --> MA4["제안 프롬프트를 누르거나<br/>직접 입력"]
    MA4 --> MA5["첫 답변 받음"]
    MA5 --> MA6{"이어서 물어볼까?"}
    MA6 -->|"예"| MA4
    MA6 -->|"아니요"| MA7(["앱 종료 — 다음에 다시"])
```

**Flow B. 매일의 핵심 루프 — 질문 ↔ 답변**

```mermaid
flowchart TD
    MB1(["앱 실행"]) --> MB2["S1. 채팅 화면<br/>로그인 과정 없이 바로 도착"]
    MB2 --> MB3["질문 입력 · 전송"]
    MB3 --> MB4["답변이 실시간으로 출력됨<br/>— 스트리밍"]
    MB4 --> MB5{"다음 행동은?"}
    MB5 -->|"꼬리 질문"| MB3
    MB5 -->|"새 주제"| MB6["새 채팅 시작 ✎"]
    MB6 --> MB3
    MB5 -->|"용무 끝"| MB7(["앱 종료"])

    classDef hot fill:#dbeafe,stroke:#2563eb,color:#1e3a8a;

```

```mermaid

    MC3 -->|"검색"| MC4["검색어 입력"]
    MC3 -->|"스크롤"| MC5["날짜 그룹 목록<br/>오늘 / 어제 / 지난 7일"]

    MC5 --> MC6
```
