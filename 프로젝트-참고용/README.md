# 프로젝트 참고용 — 챗봇 화면 분석 모음

우리 챗봇의 화면을 정하기 전에, 이미 검증된 챗봇 3개를 **같은 틀(1 IA → 2 User Flow → 3 Wireframe)**로 분석해 모아 둔 폴더입니다. 각 분석은 데스크톱 → 모바일 순서로 정리되어 있습니다.

| 폴더 | 내용 |
|---|---|
| [웹-claude-ai](./웹-claude-ai/) | Claude 분석 — 아티팩트 패널이 특징 |

| [공통점](./공통점/) | 셋에서 똑같이 반복되는 뼈대 정리 — **우리 챗봇 설계의 기준** |

**추천 읽는 순서** — 아무 서비스 하나를 훑은 뒤 [공통점](./공통점/)을 읽으면, 무엇이 표준이고 무엇이 각자의 개성인지 한 번에 보입니다.
